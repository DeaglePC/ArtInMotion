# 从画法名称选择落笔方式 · Choosing a technique

同一种材料可以画出不同效果。先看用户指定的痕迹和动作，再决定预设。下表给出常见起点。最后一列适用于用户明确强调该特征时，助手可以据此编写笔触计划或新的取样函数。

| 用户说的画法 | 接近的预设 | 更细的处理 |
|---|---|---|
| 铅笔速写、白描、连续线画 | contour | 从照片边缘取长线；连续线画需要自行连接路径。 |
| 钢笔、圆珠笔、针管笔、铜版排线 | hatching | 以一组平行线起稿，暗部再交叉排线。 |
| 炭笔、石墨、红垩、银尖笔 | charcoal / contour | 炭笔叠暗并保留纸纹；红垩改用赭红，银尖笔用浅灰细线。 |
| 彩色铅笔、粉彩铅笔 | colored-pencil | 用细线顺着形体排，分层交叠，保留纸纹。 |
| 写意水墨、彩墨、透明水彩 | ink-wash / watercolor | 先淡后浓；留白处跳过落笔，浓色可提高 pigment。 |
| 工笔、重彩、细密画 | gongbi | 分区铺色后勾线，纹样需要额外路径。 |
| 古典油画、蛋彩、丙烯、水粉、壁画 | realist / flat / impasto | 按薄层、平面色块或厚笔选择；湿壁画表面可另加灰泥质感。 |
| 印象派笔触、厚涂、刮刀画 | impasto | 刮刀可用细长多边形色片与一侧亮边。 |
| 色粉、粉笔、油画棒、蜡笔 | pastel / crayon | 保留纸底，区分柔和粉层与蜡质粗线。 |
| 动漫赛璐璐、海报、波普 | flat / stipple | 先平涂，再加墨线或按明度分布的网点。 |
| 木刻、橡皮章、丝网版画、套色木版 | woodcut / block-print | 黑白刻线用减色顺序，套色版按色版顺序叠印。 |
| 点彩、喷绘、喷漆涂鸦 | stipple | 喷绘可按离喷嘴中心的距离降低点密度；字形需要自定笔迹。 |
| 剪纸、拼贴、马赛克、彩窗 | collage / facets | 依次放置剪影、纸片或色块；彩窗用粗线连接色块边界。 |
| 沙画、粉粒画、撒点画 | sand | 先在暖色灯箱上铺沙，再推薄亮面，让部分沙堆到指痕两侧，最后沿轮廓划出窄沟。 |
| 拓印、水拓、流体纹样 | marbling | 用曲线和色带排布纹路；按指定涡心变形需自定坐标。 |
| 低多边形、立体主义式切面、几何抽象 | facets | 特定构图可直接安排相交色面及叠放顺序。 |
| 像素画、字符画、十字绣图样 | pixel | 像素使用方格；字符须按亮度排字形路径，绣线可用交叉短线。 |
| 书法、篆刻、装饰纹样、曼荼罗 | 自定义计划 | 由助手提供实际字形或纹样路径，安排起收笔、落印或径向重复。 |

For other media, specify the ground, mark geometry, color and opacity, mark order, and visible tool. Use the [plan format](marks.md) for a single piece. For a repeatable photo treatment, add a generator that derives these marks from the input. Describe the particular visible effect that the renderer implements.
